## 🚀 Quick Start

<div align="center">

### Step 1️⃣: Clone Repository

</div>

```bash
git clone https://github.com/your-username/scientific-calculator.git
cd scientific-calculator
```

<div align="center">

### Step 2️⃣: Create Virtual Environment (Recommended)

</div>

<table>
<tr>
<td width="50%">

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

</td>
<td width="50%">

**macOS/Linux:**
```bash
python -m venv venv
source venv/bin/activate
```

</td>
</tr>
</table>

<div align="center">

### Step 3️⃣: Install Dependencies

</div>

**For CLI Calculator Only:**
```bash
pip install numpy
```

**For Both CLI and GUI:**
```bash
pip install numpy customtkinter
```

**Or use requirements file:**
```bash
pip install -r requirements.txt
```

**Verify installation:**
```bash
python -c "import numpy, customtkinter; print('All dependencies installed!')"
```

<div align="center">

### Step 4️⃣: Run the Calculator

</div>

**CLI Version (Command Line):**
```bash
python calculator.py
```

**GUI Version (Graphical Interface):**
```bash
python Calculator_GUI.py
```

## 💻 Usage Guide

<div align="center">

### CLI Calculator (calculator.py)

</div>

**Features:**
- 📋 Interactive menu with 9 operations
- 🎨 Color-coded output for better readability
- 🔄 Continuous calculation mode
- ✅ Error handling with clear messages

**Usage Flow:**

```
1. Run: python calculator.py
2. Select operation number (1-9)
3. Enter required numbers
4. View result
5. Press Enter to calculate again
6. Press any other key + Enter to exit
```

**Example Session:**
<div align ='center'>
  
```bash
$ python calculator.py

Select operation :

1. Addition
   2. Subtraction
      3. Multiplication
4. Division
   5. Power (x^y)
   6. Square Root
 7. Cube Root
           8. Logarithm (base 10)
              9. Natural Logarithm (ln)

Enter choice (1-9) : 5

You choose to 'Check Exponential value'

  Enter base   : 2
Enter exponent : 10
─────────────────────────────────────────
Exponential value is = 1024.0
─────────────────────────────────────────

Press Enter to calculate again
```
</div>
  
<div align="center">

### GUI Calculator (Calculator_GUI.py)

</div>

**Features:**
- 🖱️ Click buttons or use keyboard
- 📱 Responsive, resizable window
- 🎨 Modern dark theme with green accents
- ⌫ Backspace for corrections
- 🔄 Clear button to reset

**Usage:**

```
1. Run: python Calculator_GUI.py
2. Click number buttons or type directly
3. Click operation buttons (+, -, ×, ÷)
4. Use parentheses ( ) for complex expressions
5. Press = to calculate result
6. Use C to clear, ⌫ to backspace
```

**Keyboard Shortcuts:**
- `0-9` - Enter numbers
- `+` `-` `*` `/` - Operators
- `(` `)` - Parentheses
- `.` - Decimal point
- `Enter` - Calculate (=)
- `Escape` - Clear (C)
- `Backspace` - Delete last character

**Example Expressions:**
```
Simple:        25 + 75 = 100
Complex:       (10 + 5) * 2 = 30
Decimal:       3.14 * 2 = 6.28
Nested:        ((5 + 3) * 2) - 4 = 12
```

### CLI Output Customization

</div>

**ANSI Color Codes in `calculator.py`:**

```python
# Color Codes
\033[34m  # Blue (for prompts)
\033[32m  # Green (for results)
\033[33m  # Yellow (for hints)
\033[35m  # Magenta (for goodbye)
\033[3m   # Italic
\033[0m   # Reset formatting

# Example: Change result color from green to cyan
print(f"Result = \033[36m {result} \033[0m")  # Cyan
```

**Disable Colors (for unsupported terminals):**
```python
# Remove all \033[...m codes for plain text output
print(f"Result = {result}")
```

class CalculatorHistory:
    def __init__(self):
        self.history = []
        self.max_size = 50
    
    def add_calculation(self, expression, result):
        """Add calculation to history"""
        self.history.append({
            'expression': expression,
            'result': result,
            'timestamp': datetime.now()
        })
        if len(self.history) > self.max_size:
            self.history.pop(0)
    
    def get_history(self, n=10):
        """Get last n calculations"""
        return self.history[-n:]
    
    def clear_history(self):
        """Clear all history"""
        self.history = []
    
    def save_to_file(self, filename='calc_history.txt'):
        """Save history to file"""
        with open(filename, 'w') as f:
            for calc in self.history:
                f.write(f"{calc['timestamp']}: {calc['expression']} = {calc['result']}\n")

# Usage

## 🐛 Troubleshooting

<div align="center">

### Common Issues & Solutions

</div>

<details>
<summary><b>❌ Module Not Found: customtkinter</b></summary>

**Symptoms:**
```
ModuleNotFoundError: No module named 'customtkinter'
```

**Solutions:**

1. **Install CustomTkinter:**
   ```bash
   pip install customtkinter
   ```

2. **Verify Installation:**
   ```bash
   pip list | grep customtkinter
   ```

3. **Use Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   pip install customtkinter
   ```

4. **Alternative: Use Standard Tkinter:**
   If CustomTkinter doesn't work, modify code to use standard Tkinter:
   ```python
   import tkinter as tk
   # Replace ctk with tk
   ```

</details>

<details>
<summary><b>🖥️ GUI Window Not Appearing</b></summary>

**Symptoms:**
- Script runs but no window shows
- Window appears then immediately closes

**Solutions:**

1. **Check Display Environment (Linux):**
   ```bash
   echo $DISPLAY
   # Should output something like :0 or :1
   ```

2. **Test Tkinter Installation:**
   ```python
   python -c "import tkinter; tkinter.Tk()"
   # Should show empty window
   ```

3. **macOS: Grant Terminal Access:**
   - System Preferences → Security & Privacy
   - Allow Terminal to control computer

4. **Windows: Update Graphics Drivers**

5. **Add Error Handling:**
   ```python
   try:
       app = ctk.CTk()
       app.mainloop()
   except Exception as e:
       print(f"GUI Error: {e}")
   ```

</details>

<details>
<summary><b>🔢 Calculation Errors in GUI</b></summary>

**Symptoms:**
- "Error" displayed frequently
- Unexpected results

**Solutions:**

1. **Check Expression Syntax:**
   - Ensure balanced parentheses
   - Use `*` for multiplication (not `×`)
   - Avoid starting with operators

2. **Division by Zero:**
   ```python
   # Add check before eval
   if '/0' in expression or '÷0' in expression:
       equation.set("Cannot divide by zero")
       return
   ```

3. **Add Expression Validation:**
   ```python
   def is_valid_expression(expr):
       """Check if expression is valid"""
       try:
           # Check balanced parentheses
           if expr.count('(') != expr.count(')'):
               return False
           # Test evaluation without executing
           compile(expr, '<string>', 'eval')
           return True
       except:
           return False
   ```

4. **Safe Eval:**
   ```python
   import ast
   import operator
   
   # Use safer eval with limited operators
   safe_operators = {
       ast.Add: operator.add,
       ast.Sub: operator.sub,
       ast.Mult: operator.mul,
       ast.Div: operator.truediv,
       ast.Pow: operator.pow,
   }
   ```

</details>

<details>
<summary><b>🎨 Colors Not Displaying (CLI)</b></summary>

**Symptoms:**
- ANSI codes visible as text
- No colored output in terminal

**Solutions:**

1. **Windows: Enable ANSI Support:**
   ```python
   import os
   os.system('color')  # Enable ANSI in Windows CMD
   ```

2. **Use colorama (cross-platform):**
   ```bash
   pip install colorama
   ```
   ```python
   from colorama import init, Fore, Style
   init()  # Initialize colorama
   
   print(f"{Fore.GREEN}Result = {result}{Style.RESET_ALL}")
   ```

3. **Disable Colors:**
   ```python
   # Remove all \033[...m codes
   print(f"Result = {result}")  # Plain text
   ```

</details>

ModuleNotFoundError: No module named 'numpy'
ImportError: numpy.core.multiarray failed to import

**Solutions:**

1. **Install NumPy:**
   ```bash
   pip install numpy
   ```

2. **Upgrade NumPy:**
   ```bash
   pip install --upgrade numpy
   ```

3. **Check Python Version:**
   ```bash
   python --version
   # NumPy requires Python 3.8+
   ```

4. **Reinstall NumPy:**
   ```bash
   pip uninstall numpy
   pip install numpy
   ```
