# Scientific Calculator (Python)

A **Python-based Scientific Calculator** built with a clean separation of logic and interface, designed to handle both **basic arithmetic** and **advanced mathematical operations** with reliability and precision.

This project demonstrates strong fundamentals in **Python programming**, **numerical computation**, and **GUI-based application design**.

---

## 🚀 Features

### Core Operations
- Addition, subtraction, multiplication, division  
- Power and root calculations  
- Logarithmic functions  
- Trigonometric support (if enabled via NumPy)

### Technical Highlights
- Uses **NumPy** for accurate and efficient numerical computation  
- Modular design: computation logic separated from the UI  
- GUI-based calculator for improved usability  
- Error handling for invalid inputs and edge cases  

---

## 🛠 Tech Stack

- **Language:** Python 3  
- **Libraries:**  
  - NumPy – numerical computations  
  - Tkinter – GUI interface (for GUI version)
